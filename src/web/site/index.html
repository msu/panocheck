Panocheck

Panocheck checks a document for accessibility issues, offers to fix them and provides a corrected download.

It is intended to help people produce accessible documents that satisfy Canvas/YuJa Panorama accessibility requirements.

Privacy: Panocheck has no server and keeps all data on your machine. Its security policy blocks all network requests. Because no data leaves your computer it is FERPA compliant.

The score is an estimate. Use it only to compare versions of a file.

Preview

Panocheck is open source and is provided "AS IS".

A sibling python library is available for command line tools and agent usage.

Note that automatic checks augment but do not replace manual document review.
